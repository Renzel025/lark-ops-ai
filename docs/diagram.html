Deployment: Lark Cloud → Your server (ECS Aliyun) → Groq / Claude / Lark API

Lark Cloud pushes webhooks to your domain. nginx terminates TLS and forwards to lark-ops-ai.service (uvicorn on port 8000). Your Python code then calls outbound APIs to reply in Lark and run AI.
